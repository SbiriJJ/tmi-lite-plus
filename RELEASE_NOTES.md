# Prompt Lite+ 1.6

Status: stable release  
Release date: 28 September 2026  
Platform: Windows x64, Release configuration  
Executable version: 1.6.9767.24629 (G.T generated by the compiler)  
Minimum/tested Codex CLI: 0.157.1

## Main changes

- Server-owned projects replace directory-derived project reconstruction.
  Ordinary startup reads the server project catalog; thread metadata is loaded
  when a group is expanded or a search is requested.
- A Raize grouped browser combines projects and their threads in one panel.
  It opens at startup and expands the last-used project once its list is ready
  and visible, without resuming any thread.
  **Show Threads / Show Current** describes the toggle's next action.
- Global title search with an integrated magnifier/clear button and
  **Show archived** (archived threads only). Enter searches; Esc clears while
  the field has focus. Editing and clearing restore the magnifier.
  Clicking an active thread opens it; archived entries are selected without resume.
- Row-targeted context menus provide New, Duplicate, Rename, assignment,
  Archive/Unarchive and confirmed deletion where applicable.
  Project deletion preserves its threads as unassigned. Thread deletion is
  permanent and includes spawned descendants.
- Active thread name, project and working directory are displayed separately.
  Assigning a project does not move files or change cwd. Changing cwd uses the
  server settings and applies to subsequent turns without moving existing files.
- **Project roots** lists the server roots and fills missing roots from associated
  thread directories. Add/Browse/Remove manage the list; roots used by threads
  cannot be removed. **Assign to thread** affects only the current idle thread.
  **Assign to project** can create a new named project and always preserves cwd.
- Conversation caching is optional in Config (enabled by default). Date displays
  follow Windows preferences. Longer working-directory hints and a bounded Usage
  chart tooltip improve readability without adding polling.
- Browser headings/items use normal weight; only the active project/thread names
  in the main header are bold. Working directory has a separate path line.
- Unassigned threads remain unassigned until explicitly changed; no automatic
  metadata rewrites occur during catalog loading.
- Modeless content search returns matching-message excerpts with explicit
  pagination and Stop. Opening a result uses the normal thread ownership path.
- Activity includes available server tool timing, or explicitly local elapsed
  time between events. No estimated per-tool token costs or new polling.
- MCP opens an on-demand runtime inventory of MCP servers, connectors and
  background terminals actually exposed by the server.
- Enter in other editors no longer triggers the prompt's Append button.
  Enter in Find searches; Ctrl+Enter in the prompt retains prompt submission.

## Retained features

Full Load retains its previous summary retrieval, local search and partial-stop
behavior. Normal bounded conversation loading is unchanged. Account Usage
charts, Unicode formulas, local image viewing, reset-credit information and
other preceding Rolling features remain available. Optional MicroTeX rendering
is not bundled; see MICROTEX_SETUP.md.

## Scope and verification

Prompt queue automation, generic plugin UI hosting and historical per-item
timing remain deferred; they are not part of version 1.6.
The experimental replacement for Full Load was not retained.

Grouped-control/DFM, catalog and isolated server-protocol checks passed during
development. Working-directory persistence and project deletion behavior were
tested without mutating real user threads. The user also checked the new browser.
Final Release/Win64 compilation and targeted UI/root-dialog checks passed.
These checks do not replace testing on every Windows or Codex configuration.
Known cosmetic limitation: the Raize embedded search button can use a lighter
background while focused. The larger glyph and search/clear actions are retained.

## Publication and updates

Published as **v1.6**, the latest stable release. Release-channel checks can offer
this version. The existing Rolling tag and its assets are unchanged.
Preserve the installed INI when upgrading manually; the package contains neutral
defaults for a fresh installation. Previous ZIP archives remain unchanged.
